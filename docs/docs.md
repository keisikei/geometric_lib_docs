# Документация Geometric Lib

## Описание решения
Проект представляет собой библиотеку для расчета геометрических фигур 
В этой версии реализован расчет площади и периметра для прямоугольника и треугольника
Данная библиотека предназначена для упрощения математических вычислений в разных прикладных задачах

## Описание функций

### Файл rectangle.py. Функция area(a, b)
- **Описание:** Вычисляет площадь прямоугольника
    - `a` (int or float): ширина
    - `b` (int or float): высота
- **Пример вызова:** `area(3, 10)` выведет `30`

### Файл triangle.py. Функция perimeter(a, b)
- **Описание:** Вычисляет периметр прямоугольника
    - `a` (int or float): ширина
    - `b` (int or float): высота
- **Пример вызова:** `perimeter(100, 200)` выведет `600`

### Файл triangle.py. Функция area(a, h)
- **Описание:** Вычисляет площадь треугольника
    - `a` (int or float): ширина
    - `h` (int or float): высота
- **Пример вызова:** `area(6, 4)` выведет `12`

### Файл triangle.py. Функция perimeter(a, b)
- **Описание:** Вычисляет периметр треугольника
    - `a` (int or float): первая сторона
    - `b` (int or float): вторая сторона
    - `c` (int or float): третья сторона
- **Пример вызова:** `perimeter(6, 8, 10)` выведет `24`
