#  Geometric Lib

Рад приветствовать в **Geometric Library**!
Эта библиотека предназначена для работы с треугольниками и прямоугольниками!

## Структура проекта
- `rectangle.py` — 2 функции для работы с прямоугольниками (площадь, периметр)
- `triangle.py` — 2 функции для работы с треугольниками (также площадь и периметр)
- `docs/docs.md` — подробная документация библиотеки

##  Документация
Более подробная информация о функциях, вместе с примерами использования и историей изменения библиотеки можно посмотреть в папке [docs/docs.md](./docs/docs.md)
